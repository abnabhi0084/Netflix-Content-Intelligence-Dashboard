# 🎬 Netflix Content Intelligence Dashboard

## 📌 Project Overview

This project is a Data Analytics + Machine Learning dashboard built
using Python and Streamlit.\
It analyzes Netflix content and provides interactive insights along with
a movie recommendation system.

------------------------------------------------------------------------

## 🚀 Features

-   Data analysis of Netflix content
-   Content-based recommendation system (TF-IDF + Cosine Similarity)
-   Interactive Streamlit dashboard

------------------------------------------------------------------------

## 🧠 How It Works

1.  Combine title, genre, and description\
2.  Convert text into numbers using TF-IDF\
3.  Compute similarity using cosine similarity\
4.  Recommend similar content

------------------------------------------------------------------------

## 📂 Project Structure

-   app.py → Streamlit app\
-   notebook.ipynb → Analysis + ML\
-   netflix_titles.csv → Dataset

------------------------------------------------------------------------

## ⚙️ Setup

Install dependencies: python -m pip install pandas numpy scikit-learn
streamlit

Run app: python -m streamlit run app.py

------------------------------------------------------------------------

## ⚠️ Note

Recommendations depend on dataset availability.
